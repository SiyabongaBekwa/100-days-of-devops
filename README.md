# 100 Days of DevOps

My hands-on journey through the KodeKloud **100 Days of DevOps** challenge.

This repository documents the practical tasks, commands, troubleshooting steps, and concepts I learn throughout the challenge.

The goal is to build practical DevOps skills through consistent hands-on work with Linux, Git, Docker, Kubernetes, CI/CD, automation, infrastructure as code, and cloud technologies.

## Documentation Approach

Each completed challenge is documented with:

* Challenge overview
* Objective
* Environment
* Implementation steps
* Commands used
* Verification
* Key concepts
* DevOps relevance
* Lessons learned
* Security considerations
* Challenge status

Where applicable, troubleshooting steps and failed commands are also documented to show the problem-solving process rather than only the final solution.

Sensitive information such as passwords, private keys, tokens, and other credentials is intentionally excluded.

## DevOps Journey

This repository represents an ongoing practical learning journey from foundational Linux and Git skills toward more advanced DevOps and cloud engineering capabilities.

The progression is focused on developing the ability to:

**Build → Configure → Troubleshoot → Automate → Deploy → Operate**

The remaining challenges will continue expanding this foundation into containers, Kubernetes, CI/CD, configuration management, infrastructure as code, and cloud infrastructure.
